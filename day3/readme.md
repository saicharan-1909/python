# 🧮 Day 3 - Menu-Based Calculator

## 📖 Description

This project is a simple menu-driven calculator built using Python functions.

The user can choose from the following operations:

- Addition
- Subtraction
- Multiplication
- Division
- Exit

The program keeps running until the user chooses the Exit option.

---

## 🎯 Features

- Menu-driven interface
- Addition
- Subtraction
- Multiplication
- Division
- Repeats until the user exits
- Beginner-friendly console application

---

## 🛠 Concepts Used

- Functions
- Parameters
- Return Values
- While Loop
- If-Elif-Else
- User Input
